zinc

A free, self-hosted long-URL generator on Cloudflare Quick Tunnels.

Turn any link into a secret URL. See who opened it, change where it goes, destroy it. No account, no server, no domain.

Install Download GitHub

Features

Gates

plain, note, count, box, door

Routing

A/B splits, by country, language, device

Adaptive locale

Send visitors to localized page

Limits

Lifetime, max visitors, password, start time

Dashboard

Opens, uniques, passes, bots, sparkline, export

Safety

Scanner, VirusTotal, Safe Browsing, URLhaus

Install

pip install zinc-link

python -m zinc

Or download binary from Releases page.

Debian/Ubuntu: sudo dpkg -i zinc_0.1.2_amd64.deb

Windows: winget install zien0709.zinc

macOS: brew tap zien0709/tap && brew install zinc

Windows (Scoop): scoop bucket add zien0709 https://github.com/zien0709/scoop-bucket && scoop install zinc
